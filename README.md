## Featured Projects

### Tron BattleTanks (C++ / SDL2)
A small game + engine-style architecture project focused on gameplay systems.

- ECS game object setup, scene management, input commands
- Collision, AI, audio, and gameplay loop structure

**Repo:** [Tron BattleTanks](https://github.com/BeHaVeZ/FMLEngine-Tron_BattleTanks)


### The Three Dolls (Unity / C#)
A gameplay-focused Unity project where I helped building the core mechanics and interactive systems with iteration in mind for a jam with others.

- Player interactions
- AI behaviors and tuning hooks for gameplay feel (Event system hooks for thunder / sounds / horror etc...)
- Game design

**Link:** [Itch page](https://behavez.itch.io/the-three-dolls)


### Space Combat Arena | Dynamic Difficulty Adjustment (Unity / C#)
A research-driven prototype exploring Player-Centric Dynamic Difficulty Adjustment (DDA) in a combat arena.

- Difficulty adapts in real time using performance metrics (PCDA-style approach)
- Built to evaluate impact on challenge and player experience

**Repo:** [Space Combat Arena](https://github.com/BeHaVeZ/BeHaVeZ-DDA_GW2024-25)
